- **CogR-VOS** (capstone, ongoing): training-free pipeline that keeps a language-referred target's identity through occlusion and look-alikes, using frozen Grounding DINO, SAM 2.1, DINOv2, CLIP and the Gemini API. Five versions (V0 to V4) add a bounded target memory, a temporal coherence score, event-triggered VLM calls and memory-based re-identification. Evaluated on Ref-DAVIS17 (J&F 50.48 to 50.97) with about 52x fewer VLM calls than querying every frame, all on a 4 GB laptop GPU.
- **Edge-Cloud Predictive Maintenance**: TensorFlow CNN-LSTM model for Remaining Useful Life estimation (RMSE 57.29 on IndFD-PM-DT) paired with a real-time digital twin. I owned the backend: API server, SimPy simulation engine and adaptive routing policies, containerized with Docker Compose.
- **Zephra**: 4-member team building a full-stack air quality platform that merges NASA TEMPO/MERRA-2/MODIS satellite data with ground-station data for real-time and 12-hour AQI forecasts. I worked on the async FastAPI backend and contributed to the React/TypeScript frontend.
- **sdn_iot_security**: secure IoT communication prototype with ECC key exchange, AES-256-GCM encryption, WAV audio steganography, replay protection, reliable UDP file transfer and SDN-based routing support.
